# Balises communes

Ces blocs sont disponibles dans le gabarit de chaque type de document.

| Balise | Type | Description |
|---|---|---|
| `onea` | bloc | Organisme émetteur |
| `onea.nom` | texte | Nom complet de l'ONEA |
| `onea.sigle` | texte | Sigle de l'ONEA |
| `onea.departement` | texte | Département émetteur |
| `document` | bloc | Informations du document généré |
| `document.numero` | texte | Numéro définitif du document |
| `document.version` | texte | Numéro de version du document |
| `document.type` | texte | Libellé du type de document |
| `document.genere_le` | texte | Date de génération (JJ/MM/AAAA) |
| `document.genere_par` | texte | Nom de la personne qui a généré le document |
