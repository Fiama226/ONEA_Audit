# Lot 1 — Socle technique : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Livrer un monorepo démarrable en une commande, avec un backend Django authentifié par Keycloak et des rôles, une piste d'audit, un frontend React avec shell institutionnel et connexion, un contrat OpenAPI typé, Celery/e-mail, et une CI verte.

**Architecture:** Monorepo `backend/` (Django 5, DRF, apps `core` et `users`) + `frontend/` (Vite, React 19, shadcn) + `docker/` (Compose, Nginx). L'authentification est déléguée à Keycloak (OIDC) ; le frontend obtient un token avec oidc-client-ts et l'API le vérifie. Le contrat d'API est généré par drf-spectacular et consommé par openapi-typescript.

**Tech Stack:** Python 3.12, Django 5.1, DRF 3.15, drf-spectacular, django-auditlog, django-environ, mozilla-django-oidc, Celery 5, pytest, factory_boy ; Node 22, React 19, TypeScript 5, Vite 6, Tailwind 4, shadcn/ui, TanStack Query 5, React Router 7, oidc-client-ts, zod, Vitest, MSW, Playwright ; PostgreSQL 16, Redis 7 (Valkey), Keycloak 26, MinIO, Meilisearch 1.x, Gotenberg 8, Mailpit (dev).

**Spec:** `docs/superpowers/specs/2026-10-27-plateforme-audit-interne-design.md` (sections 3, 4, 5, 6.10, 9, 10, 11 lot 1, 14 « Confidentialité », 15.3).

## Global Constraints

- Aucune fonctionnalité IA / LLM ; aucune dépendance non open source (MIT, BSD, Apache 2.0, PostgreSQL, LGPL, AGPL).
- Interface et messages en français ; identifiants de code, commits en anglais (Conventional Commits).
- Rôles globaux exactement : `ADMIN`, `RAI`, `AUDITEUR`, `AUDITE`, `DG`.
- Toute entité métier hérite de `core.models.BaseModel` (UUID, timestamps, auteur, soft delete) et est enregistrée dans auditlog.
- Format d'erreur API unique : `{"detail": str, "errors": {champ: [messages]}}`, HTTP 422 pour les erreurs métier.
- Fuseau d'affichage `Africa/Ouagadougou`, stockage UTC, `USE_TZ = True`, `LANGUAGE_CODE = "fr"`.
- Pas de secret en dur ; variables via `.env` (`django-environ`), `.env.example` commité.
- Tests backend sur PostgreSQL réel (jamais SQLite). Couverture cible 85 % backend, 80 % frontend.
- Charte : tokens CSS uniquement, aucune couleur hexadécimale dans un composant.

## Review Focus

1. Un token OIDC expiré ou signé par un autre realm doit donner 401 avec un message français, jamais 500 (test en Task 5).
2. Un utilisateur Keycloak sans rôle mappé doit être créé avec le rôle par défaut `AUDITE` et ne voir que le tableau de bord vide (test en Task 5 et Task 9).
3. Une erreur de validation DRF sur un champ imbriqué doit sortir au format `errors` uniforme, pas au format brut DRF (test en Task 3).
4. Un objet soft-deleted ne doit apparaître dans aucune liste par défaut mais rester accessible via `all_objects` et dans auditlog (test en Task 3).
5. Le frontend doit afficher un écran d'erreur lisible, pas une page blanche, si l'API ou Keycloak est injoignable au chargement (test en Task 8).
