# Manuel du Responsable de l'audit interne (RAI)

Plateforme d'audit interne ONEA — Département Audit Interne (DAI).
Ce manuel s'adresse au compte au rôle « RAI » (Responsable de l'audit interne). Le RAI pilote le programme
annuel, lance les missions, valide les jalons, diffuse les rapports et suit les recommandations jusqu'à
la clôture.

## 1. Prise en main

### 1.1 Se connecter

1. Ouvrez l'adresse de la plateforme dans Chrome ou Edge. La page « Connexion » s'affiche, avec
   « Connectez-vous avec votre compte ONEA pour accéder à la plateforme ».
2. Saisissez votre « Identifiant ou courriel professionnel » et votre « Mot de passe », puis cliquez sur
   « Se connecter ».
3. Vous arrivez sur votre tableau de bord.

**Première connexion.** Votre compte est créé par l'administrateur, qui vous communique (ou vous envoie par
courriel) un mot de passe temporaire valable 72 heures. À la première connexion, la plateforme affiche
« Changer le mot de passe » : saisissez le mot de passe temporaire dans « Mot de passe actuel », choisissez un
nouveau mot de passe d'au moins 12 caractères (évitez un mot de passe courant ou proche de votre identifiant),
confirmez-le, puis cliquez sur « Changer le mot de passe ». Vous accédez ensuite à la plateforme. Passé les 72
heures, le mot de passe temporaire n'est plus accepté : demandez à l'administrateur de le réinitialiser.

**Mot de passe oublié.** Sur la page « Connexion », cliquez sur « Mot de passe oublié ? », indiquez votre
identifiant ou votre courriel professionnel, puis cliquez sur « Recevoir un code ». Si un compte correspond, un
code à 6 chiffres vous est envoyé par courriel (valable 10 minutes) ; le message affiché est le même que le
compte existe ou non. Cliquez sur « Saisir le code reçu », saisissez le code et un nouveau mot de passe, puis
« Enregistrer le mot de passe ». Si aucun courriel n'arrive, adressez-vous à l'administrateur : il peut
réinitialiser votre mot de passe.

**Connexion refusée.** Le message « Identifiant ou mot de passe incorrect. » est le même quelle que soit la cause
(mot de passe erroné, compte inconnu, désactivé ou verrouillé). Après cinq échecs consécutifs, la connexion est
bloquée pendant 15 minutes ; l'administrateur peut la rétablir plus tôt en réinitialisant votre mot de passe.

**Durée de la session.** Votre session se ferme après 8 heures, ou après 30 minutes sans activité : « Votre
session a expiré. Veuillez vous reconnecter. »

[Capture à insérer : CAP-COM-01 — Page de connexion]
[Capture à insérer : CAP-RAI-01 — Tableau de bord du RAI]

Si votre session expire, le message « Votre session a expiré. Veuillez vous reconnecter. » s'affiche ;
reconnectez-vous.

### 1.2 Naviguer

La barre latérale, à gauche, regroupe les entrées par thème. Pour le RAI :

| Groupe | Entrées visibles |
|---|---|
| (sans titre) | « Tableau de bord » |
| « Conduite des missions » | « Programme annuel », « Missions », « Référentiel » |
| « Suivi » | « Recommandations », « Rapports diffusés », « Documents » |
| « Paramétrage » | « Gabarits de documents » (en lecture seule) |

L'entrée « Administration » n'est pas proposée au RAI : elle est réservée à l'administrateur.

- « Replier le menu » réduit la barre à ses icônes ; « Déplier le menu » la restaure. Sous 1024 px de
  largeur, le menu devient un tiroir (« Ouvrir le menu » / « Fermer le menu »).
- Le fil d'Ariane, au-dessus du contenu, permet de remonter d'un niveau.
- Au clavier, la touche Tab fait d'abord apparaître « Aller au contenu principal ».
- La recherche globale se trouve dans l'en-tête (voir 7.4) et la cloche affiche vos notifications (voir 7.3).

[Capture à insérer : CAP-RAI-02 — Barre latérale et en-tête du RAI]

### 1.3 Votre profil et le menu utilisateur

En haut à droite, le menu utilisateur affiche votre nom, votre adresse et votre rôle. Il propose
« Mon compte », « Changer mon mot de passe », « Visite guidée de la plateforme » et « Se déconnecter ».
Dans « Mon compte », vous pouvez changer votre mot de passe (vos autres sessions ouvertes sont alors fermées) et
activer ou désactiver, **vous seul**, le réglage facultatif « Demander un code par courriel à chaque connexion »
(désactivé par défaut). Activé, ce réglage ajoute après le mot de passe l'étape « Vérification en deux étapes » :
saisissez le code à 6 chiffres reçu par courriel (valable 10 minutes), puis « Valider le code ». Il ne peut être
activé que si l'envoi de courriels est configuré et si une adresse de courriel est enregistrée sur votre compte ;
pour le désactiver, confirmez avec votre mot de passe actuel. Si le code ne vous parvient plus, l'administrateur
peut le désactiver pour vous (mais jamais l'activer à votre place).

Le nom, l'adresse, le rôle, la direction, la fonction et le matricule sont renseignés par l'administrateur
(ou un délégué) ; vous ne les modifiez pas vous-même.

[Capture à insérer : CAP-COM-02 — Menu utilisateur ouvert]

### 1.4 Aide

Aucune entrée « Aide » n'existe encore dans le menu (voir « À confirmer »). Ce manuel et le glossaire en
tiennent lieu.

### 1.5 Se déconnecter

Ouvrez le menu utilisateur puis « Se déconnecter ». Les adresses de l'application ne sont plus
accessibles sans nouvelle connexion.

## 2. Préparer le socle : référentiel et programme annuel

Le RAI écrit dans le référentiel (cartographies, risques, processus, directions, objets auditables) et
dans le programme annuel. L'administrateur écrit aussi dans les directions et les processus.

### 2.1 Ajouter ou modifier des processus et des directions

1. « Référentiel », onglet « Processus » : « Créer un processus ». Saisissez un code de 3 lettres
   majuscules (le code ne peut plus être modifié après la création), un libellé, une famille et les
   directions rattachées.
2. Onglet « Directions » : « Ajouter une direction ou un département ». Un département doit être
   rattaché à une direction.
3. Pour retirer un élément, utilisez « Supprimer le processus » (ou équivalent) puis confirmez ; la
   suppression est logique et tracée.

Messages possibles : « Deux à cinq lettres majuscules, sans accent. », « Le libellé est obligatoire. »,
« Choisissez une famille. », « Un département doit être rattaché à une direction. »

[Capture à insérer : CAP-RAI-03 — Référentiel, onglet Processus]

### 2.2 Objets auditables

Onglet « Objets auditables » : choisissez un processus, puis « Ajouter un domaine » et, dans le domaine,
« Ajouter une opération ». Vous pouvez modifier et supprimer. L'arbre se parcourt aux flèches haut/bas.

### 2.3 Créer une cartographie des risques

1. « Référentiel », onglet « Cartographies » : « Créer une cartographie ». Choisissez l'année, le libellé
   et la source : « Aucune » ou « Copier les risques de » une version existante.
2. La version est créée en brouillon. Une année déjà utilisée est refusée.

### 2.4 Ajouter un risque et lire le score

1. Dans la cartographie brouillon : « Ajouter un risque ». Choisissez le processus, saisissez le libellé,
   puis la probabilité et l'impact (de 1 à 5).
2. L'aperçu affiche « Score N » et le niveau. Il est indicatif : le serveur recalcule.
3. Enregistrez. Le risque apparaît dans la matrice 5 × 5 et dans la liste (colonnes P, I, Score, Niveau,
   Priorité). Cliquez une case de la matrice pour filtrer ; « Effacer le filtre » annule.

Score = probabilité × impact. Niveaux : faible de 1 à 7, moyen de 8 à 14, élevé de 15 à 25.

[Capture à insérer : CAP-RAI-04 — Ajout d'un risque avec aperçu du score]

### 2.5 Valider une cartographie

1. Ouvrez la cartographie brouillon ; « Valider la cartographie ».
2. Lisez l'avertissement (la cartographie sera figée), puis « Valider définitivement ».
3. Un bandeau indique « Cartographie validée le … par … — lecture seule ». Plus aucune modification n'est
   possible. La cartographie validée devient la version courante pour les nouvelles missions.

[Capture à insérer : CAP-RAI-05 — Dialogue de validation d'une cartographie]

Autres actions : « Comparer avec… » (risques ajoutés, retirés, modifiés), « Exporter la cartographie »
(CSV ou Excel) et « Imprimer ».

### 2.6 Créer le programme annuel

1. « Programme annuel » : « Créer un programme ». Saisissez l'année (quatre chiffres) et le libellé.
2. « Ajouter une mission prévue » : titre, type (Assurance ou Conseil), processus, objet auditable,
   entités concernées, début et fin prévus, charge en jours, justification.
3. Les lignes se groupent par trimestre. Basculez entre « Liste » et « Calendrier ». Filtrez par
   processus, type, trimestre ; « Effacer les filtres ».
4. « Valider le programme », lisez l'avertissement puis « Valider définitivement » : le programme est figé
   (« Programme validé le … par … — lecture seule »). Seul un brouillon peut être supprimé.
5. « Exporter le programme » (CSV, Excel) et « Imprimer » sont disponibles.

Messages : « L'année doit comporter quatre chiffres. », « La fin prévue doit suivre le début prévu. »,
« La mission prévue doit commencer pendant l'année AAAA. »

[Capture à insérer : CAP-RAI-06 — Programme annuel, vue calendrier]
[Capture à insérer : CAP-RAI-07 — Formulaire d'ajout d'une mission prévue]

## 3. Créer, planifier et lancer une mission

### 3.1 Créer une mission (brouillon)

Prérequis : une cartographie validée existe, sinon « Aucune cartographie des risques validée : validez une
cartographie avant de créer une mission. »

1. « Missions » puis « Créer une mission ».
2. Renseignez : titre, type, processus audités, entités auditées, événement déclencheur, période
   auditée, dates prévues, budget en jours, objectifs, périmètre, exclusions, clients, livrables attendus.
3. « Enregistrer » : « La mission a été enregistrée. » Elle est en statut « Brouillon », sans référence.

[Capture à insérer : CAP-RAI-08 — Formulaire de création de mission]

### 3.2 Planifier

Menu « Actions sur la mission », « Planifier la mission », puis « Planifier ». La mission devient
« Planifiée » et reçoit sa référence `DAI/AAAA/Mnn` (AAAA : année du début prévu ; nn : rang, jamais
réutilisé). Si un champ obligatoire manque (processus, entités, dates), un message vous l'indique.

Seul un brouillon peut être supprimé (« Supprimer le brouillon ») ; ensuite, on annule la mission.

[Capture à insérer : CAP-RAI-09 — Menu Actions sur la mission]

### 3.3 Constituer l'équipe

1. Ouvrez la mission, onglet « Équipe », « Affecter une personne ».
2. Affectez un auditeur avec le rôle **Chef de mission**, d'autres auditeurs avec le rôle **Auditeur**,
   éventuellement un **Superviseur**, et les audités avec le rôle **Audité** (ceux rattachés aux entités de la
   mission sont pré-cochés).
3. Chaque intervenant reçoit une déclaration d'indépendance « En attente » ; l'audité est « Non requise ».
4. D'autres actions : « Remplacer le chef de mission », « Retirer de la mission », et « Arbitrer »
   (voir 8.3).

Message : « Choisissez au moins une personne. »

[Capture à insérer : CAP-RAI-10 — Onglet Équipe et dialogue d'affectation]

### 3.4 Lancer

« Lancer la mission » (confirmer « Lancer »). Un chef de mission est indispensable. La mission passe à
« En planification » et l'étape I est « En cours ».

### 3.5 Suspendre, reprendre, annuler

- « Suspendre la mission » exige un motif ; la mission passe en lecture seule.
- « Reprendre la mission » rétablit le statut précédent.
- « Annuler la mission » (avec motif) est définitif : la mission ne peut plus être modifiée ni reprise.

## 4. Conduire les 18 étapes

La mission avance de statut en statut : Brouillon, Planifiée, En planification (étapes I à X), En
accomplissement (XI à XIII), En communication (XIV à XVIII), Rapport diffusé, En suivi, Clôturée. Le passage de
phase est automatique quand toutes les étapes de la phase sont closes et que le jalon de la phase (X,
puis XIII) est validé.

Sur chaque étape, selon vos droits : « Commencer l'étape », « Terminer l'étape », « Valider le jalon »,
« Renvoyer » (motif obligatoire), « Rouvrir l'étape » (motif obligatoire), « Marquer non applicable »
(motif), « Rétablir l'étape ». « Terminer » est refusé tant que des livrables manquent : la liste
« Manquant : … » s'affiche sous l'étape. Le « Journal de l'étape » conserve chaque événement.

### 4.1 Étape I — Ordre de mission

1. Ouvrez l'étape I. Lisez le « Rappel de la mission » ; « Modifier la mission » pour compléter objectifs et
   périmètre.
2. « Émettre l'ordre de mission » : lisez le texte de confirmation, puis « Émettre l'ordre ».
3. Le message « Ordre de mission émis le … par … Empreinte : … » apparaît. « Terminer l'étape ».

Après cette étape, les champs figés (titre, type, période, objectifs, périmètre) ne se modifient plus sans
rouvrir l'étape I. Les audités ne voient la mission qu'après l'émission de l'ordre.

[Capture à insérer : CAP-RAI-11 — Étape I, émission de l'ordre de mission]

### 4.2 Étapes II à V — Équipe d'audit

Ces étapes sont conduites par l'équipe (voir le manuel de l'auditeur). Votre rôle : suivre l'avancement
dans « Fiche de suivi », répondre aux déclarations d'indépendance (8.3) et rouvrir ou renvoyer si besoin.
Étape II : « Terminer » est refusé tant que la réunion d'ouverture n'est pas tenue, qu'aucun entretien n'est
planifié ou qu'une déclaration est en attente.

### 4.3 Étape VI — Jalon : référentiel d'audit

1. Le tableau de bord signale « jalon VI à valider ». Ouvrez l'étape VI, relisez le référentiel d'audit
   (forces et faiblesses apparentes).
2. « Valider le jalon » ou « Renvoyer » avec un motif.
3. Le message « Validé le … par … — empreinte … — vérifiée » et « Version validée » confirment. L'avis de
   l'audité est enregistré mais ne bloque pas la suite.

[Capture à insérer : CAP-RAI-12 — Étape VI, validation du jalon]

### 4.4 Étapes VII à IX

Conduites par l'équipe. Le chef de mission termine l'étape IX (budget et ressources).

### 4.5 Étape X — Jalon : organisation de la mission

Après les étapes VIII et IX, le chef de mission termine la X ; vous cliquez « Valider le jalon » X. La mission
passe alors à « En accomplissement » et l'étape XI devient disponible.

### 4.6 Étapes XI à XIII — Accomplissement et jalon XIII

1. À l'étape XIII, commencez l'étape ; lisez « Fiches à valider » et la progression « n fiches validées sur N ».
2. Ouvrez chaque fiche soumise, relisez les travaux et les pièces. « Valider la fiche » (confirmer) ou
   « Renvoyer » avec le motif de renvoi. Vous ne validez pas une fiche dont vous êtes l'auteur.
3. Quand toutes les fiches sont validées : « Terminer » l'étape XIII puis « Valider le jalon ».
4. La mission passe à « En communication ».

« Rouvrir » une fiche validée exige un motif.

[Capture à insérer : CAP-RAI-13 — Fiche de test soumise, à valider]

### 4.7 Étape XIV — Constats

Vous ouvrez un constat « Soumis » et vous le validez ou le renvoyez (« Renvoyer », motif obligatoire).
Vous ne pouvez pas traiter un constat dont vous êtes l'auteur ou le soumetteur. L'étape XIV ne se termine pas s'il
reste une fiche en anomalie sans constat ou si aucun constat n'est validé.

[Capture à insérer : CAP-RAI-14 — Constat soumis, à valider]

## 5. Communiquer : rapport provisoire, validation et diffusion

### 5.1 Étape XV — Rapport provisoire

1. Planifiez puis « Marquer comme tenue » la réunion de clôture (le compte rendu doit être saisi).
2. « Transmettre le rapport provisoire » avec un délai de réponse de 1 à 60 jours. Le RAI ou le chef de
   mission peuvent transmettre. Avant la réunion tenue, le message « Tenez la réunion de clôture avant… »
   apparaît.
3. Le message « Transmis le …. Réponses attendues au plus tard le … » s'affiche. Les audités concernés sont
   notifiés.
4. Suivez le tableau « Réponses des audités » (Attendu de, Reçu le, « En attente ») et l'historique par cycle
   dans l'onglet « Rapport provisoire ». Une réponse tardive est marquée « Hors délai ».

[Capture à insérer : CAP-RAI-15 — Étape XV, transmission du rapport provisoire]
[Capture à insérer : CAP-RAI-16 — Réponses des audités]

### 5.2 Étape XVI — Plan d'actions

Les audités et l'équipe proposent des actions (voir leurs manuels). Vous consultez « Contrôles du plan
d'actions », le tableau « Engagement par responsable » et les « Recommandations sans suite ». Vous pouvez
retirer une acceptation de risque.

### 5.3 Étape XVII — Rédaction du rapport

Le chef de mission rédige et soumet le rapport. Un rapport soumis attend votre validation.

### 5.4 Étape XVIII — Valider, signer, diffuser

1. Zone « Validation du rapport » : lisez le « Mode de signature en vigueur » (par défaut « Confirmation
   horodatée »).
2. « Renvoyer » (motif obligatoire) ou « Valider le rapport » : lisez le texte, cochez « Je confirme », validez.
   Le message « Validé le … à … Empreinte : … » apparaît. Le valideur ne peut pas être la personne qui a soumis le rapport.
3. Le message « Le rapport final et la note de synthèse sont en cours de génération » s'affiche, puis les
   liens Word et PDF « Rapport final » et « Note de synthèse ».
4. **Liste de diffusion** : ajoutez des destinataires internes (avec catégorie) et externes (nom, qualité).
5. « Diffuser le rapport » : message d'accompagnement facultatif, puis confirmez.
6. La mission passe à « Rapport diffusé ». La diffusion est **irréversible** et tracée (« Diffusé le … par … »).

La diffusion est refusée si le rapport n'est pas généré, si le PDF n'est pas prêt, si la signature requise n'est pas
disponible ou si la liste est vide (« Ajoutez au moins un destinataire »).

[Capture à insérer : CAP-RAI-17 — Validation du rapport et liste de diffusion]

### 5.5 Après la diffusion

- « Suivi de la diffusion » (page du rapport diffusé) : Notifié le, Consulté le, Accusé le. Pour un
  destinataire externe, « Marquer comme remis » avec la date.
- « Émettre un rapport corrigé » (confirmer) : crée un rapport en brouillon. L'ancien reste consultable et
  porte le statut « Remplacé par un rapport corrigé » après la nouvelle diffusion. Cette correction ne
  modifie ni les étapes ni le statut de la mission.

[Capture à insérer : CAP-RAI-18 — Suivi de la diffusion d'un rapport]

## 6. Suivre les recommandations et clôturer

### 6.1 Le registre

« Recommandations » : onglets « Recommandations » et « Actions ». Filtres : Année, Mission, Entité,
Priorité, Statut, « En retard », « Mes actions ». « Réinitialiser » efface. « Exporter » (CSV, Excel, limité
à 5 000 lignes) et « Imprimer ».

[Capture à insérer : CAP-RAI-19 — Registre des recommandations et actions]

### 6.2 Traiter une action

Ouvrez l'action. Selon son statut (« À lancer », « En cours », « Réalisée, à vérifier », « Vérifiée »,
« Clôturée ») :

| Besoin | Bouton |
|---|---|
| Clôturer une action vérifiée | « Clôturer » |
| Rouvrir une action close | « Rouvrir » |
| Accepter ou refuser un report | « Accepter le report » / « Refuser le report » (commentaire obligatoire pour un refus) |
| Accepter ou rejeter un abandon | « Accepter l'abandon » / « Rejeter » |
| Confier l'action à une autre personne | « Changer le responsable » (le nouveau responsable est notifié) |

La chronologie liste chaque transition avec auteur et date. L'action garde l'échéance initiale et le
nombre de reports.

[Capture à insérer : CAP-RAI-20 — Page d'une action côté RAI]

### 6.3 Relances

Des relances partent automatiquement avant et après l'échéance (paliers : « Échéance dans 15 jours »,
« Échéance aujourd'hui », « En retard de 15 jours »). Il n'existe pas d'écran dédié : l'échec d'un envoi
s'affiche dans la file de décisions du tableau de bord (« Relances en échec », « Relances sans adresse »).

### 6.4 Clôturer la mission

1. Ouvrez la mission, onglet « Suivi des recommandations ». Tant que des actions restent ouvertes :
   « n action(s) restent ouvertes » et « La mission ne peut pas être clôturée pour le moment ».
2. Quand toutes les actions sont closes ou abandonnées, la notification « Mission à clôturer » est émise et la
   file de décisions affiche « Missions à clôturer ».
3. « Clôturer la mission » (confirmer). La mission passe en « Clôturée » et devient entièrement en lecture
   seule.

[Capture à insérer : CAP-RAI-21 — Suivi des recommandations de la mission et bouton Clôturer]

## 7. Autres écrans

### 7.1 Tableau de bord

Il comporte : les tuiles (Missions en cours, Missions en retard, Jalons à valider, Actions en retard),
« Missions par statut » (cliquer une barre ouvre la liste filtrée), la « File de décisions » (Actions à
clôturer, Abandons proposés, Reports en attente, Missions à clôturer, Relances en échec, Relances sans
adresse), « Actions par direction », la cartographie 5 × 5 et le filtre « Année ». Il s'imprime.
En cas d'échec : « Le tableau de bord n'a pas pu être chargé. » avec « Réessayer ».

[Capture à insérer : CAP-RAI-25 — File de décisions du RAI]

### 7.2 Documents

« Documents » : registre des documents générés (Word et PDF). Cherchez par numéro, filtrez par type, ouvrez un
document pour voir ses versions, son empreinte (« Copier l'empreinte ») et les consultations (qui, quand,
format). « Générer » crée un document ; « Régénérer » crée une nouvelle version sans perdre l'ancienne ;
« Télécharger (Word) » / « Télécharger (PDF) ». Si le PDF n'est pas prêt : « Le PDF n'est pas encore
disponible. » avec « Relancer le PDF ».

[Capture à insérer : CAP-RAI-22 — Registre des documents]

### 7.3 Notifications

La cloche indique « Notifications, N non lues » (« 9+ » au-delà de 9). Le menu affiche « Dernières
notifications » ; « Tout marquer comme lu » les acquitte. « Voir toutes les notifications » ouvre la page
(onglets « Non lues » / « Toutes », pagination). Exemples : « Action déclarée réalisée », « Report demandé », « Mission à
clôturer ».

### 7.4 Recherche

Saisissez au moins deux caractères dans l'en-tête puis Entrée ; filtrez par type (« Missions », « Constats »,
« Recommandations », « Actions », « Documents »). Si le service est arrêté : « La recherche est momentanément
indisponible. Réessayez plus tard. »

### 7.5 Gabarits et mode de signature (lecture seule)

« Gabarits de documents » (types, versions, balises, numérotation) et la page des modes de signature sont
consultables mais pas modifiables : « Lecture seule : seul l'administrateur peut modifier le mode de signature. »

[Capture à insérer : CAP-RAI-23 — Gabarits de documents en lecture seule]
[Capture à insérer : CAP-RAI-24 — Mode de signature en lecture seule]

## 8. Règles à connaître

### 8.1 Jalons validés par le RAI

Les jalons sont les étapes **VI** (référentiel d'audit), **X** (organisation), **XIII** (preuves) et **XVIII**
(rapport). Un superviseur peut valider VI, X et XIII par délégation ; **jamais le XVIII ni la diffusion**.

### 8.2 Le valideur n'est jamais l'auteur

Fiche : « Le valideur ne peut pas être l'auteur de la fiche. » Constat : « Vous ne pouvez pas traiter un constat
dont vous êtes l'auteur ou le soumetteur. » Rapport : « Le valideur ne peut pas être la personne qui a soumis le
rapport. » Action : la vérification revient à une autre personne que le déclarant.

### 8.3 Déclarations d'indépendance

Un intervenant ne contribue qu'après avoir confirmé sa déclaration. S'il déclare une situation à risque,
vous la traitez : onglet « Équipe », « Arbitrer », justification obligatoire, « Enregistrer l'arbitrage ». Après
arbitrage, il peut contribuer. Vous pouvez aussi le « Retirer de la mission ». La description d'un conflit est lisible par
toute l'équipe (limite connue).

### 8.4 Gels

Sont en lecture seule : une cartographie ou un programme validés, une mission suspendue, annulée ou clôturée
(« La mission DAI/AAAA/Mnn est suspendue : aucune modification n'est possible. »), une étape terminée. Pour
modifier une étape terminée, « Rouvrir l'étape » (motif obligatoire) : les jalons validés des étapes suivantes
passent « À revalider ».

### 8.5 Journal des consultations et traçabilité

Toute action est tracée (qui, quand, quoi). Les journaux visibles : « Journal de l'étape », « Journal de la
fiche », « Journal du rapport », « Chronologie » d'une action, consultations d'un document. Les objets ne sont
jamais supprimés physiquement. Le journal d'audit global n'a pas d'écran.

### 8.6 Pièces et empreintes

Une pièce déposée ne se modifie pas. Son empreinte SHA-256 est vérifiée au téléchargement ; si elle diffère :
« L'intégrité de la pièce n'a pas pu être vérifiée : le fichier est signalé comme altéré. Contactez le RAI. »
Prévenez alors le responsable technique.

### 8.7 Confirmation horodatée

La plateforme enregistre la date, l'heure et une empreinte ; ce n'est pas une signature électronique
qualifiée, qui n'est pas encore disponible.

## 10. Questions fréquentes

**Peut-on supprimer une mission ?** Seul un brouillon (« Supprimer le brouillon »). Ensuite on annule, avec un
motif.

**Peut-on modifier un rapport validé ?** Non. Utilisez « Émettre un rapport corrigé ».

**Un audité ne voit pas la mission.** L'ordre de mission n'est pas émis, ou la personne n'est pas affectée
comme « Audité », ou sa direction ne correspond pas à l'entité auditée (à régler avec l'administrateur).

**La signature électronique existe-t-elle ?** Non, pas encore ; la « Confirmation horodatée » est utilisée.

**Y a-t-il de l'intelligence artificielle ?** Non.

## 11. À confirmer

- Entrée « Aide » du menu : non présente (tâche 30).
- V-05 : disponibilité du traitement des documents (Word, PDF) dans l'environnement : sans lui, la diffusion est bloquée.
- V-06, V-07 : pas d'écran des relances ; les liens « Reports en attente », « Relances en échec » et « Relances sans adresse » mènent au registre non filtré.
- V-11 : certains textes de lots antérieurs peuvent encore s'afficher (par exemple « sera généré au lot 4 »).
- V-12 : une même personne peut-elle tenir plusieurs rôles dans une mission ?
- V-03 : deux modifications simultanées d'un même enregistrement : le dernier enregistrement l'emporte probablement, sans avertissement.
- Contenu exact des documents générés tant que les gabarits officiels ONEA manquent (V-18).
