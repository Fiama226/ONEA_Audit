# Manuel de l'audité

Plateforme d'audit interne ONEA — Département Audit Interne (DAI).
Ce manuel s'adresse aux comptes au rôle « Audité » : les personnes des directions et départements audités.
Vous consultez les missions qui vous concernent, répondez aux constats, proposez et exécutez des actions
correctives, et recevez les rapports diffusés.

## 1. Prise en main

### 1.1 Se connecter

1. Ouvrez la plateforme : la page « Connexion » s'affiche.
2. Saisissez votre « Identifiant ou courriel professionnel » et votre « Mot de passe », puis cliquez sur « Se connecter ».
3. Votre tableau de bord affiche : « Constats à répondre », « Actions ouvertes », « En retard », « Mes demandes de report ».

**Première connexion.** Votre compte est créé par l'administrateur, qui vous communique (ou vous envoie par
courriel) un mot de passe temporaire valable 72 heures. À la première connexion, la plateforme affiche
« Changer le mot de passe » : saisissez le mot de passe temporaire dans « Mot de passe actuel », choisissez un
nouveau mot de passe d'au moins 12 caractères (évitez un mot de passe courant ou proche de votre identifiant),
confirmez-le, puis cliquez sur « Changer le mot de passe ». Vous accédez ensuite à la plateforme. Passé les 72
heures, le mot de passe temporaire n'est plus accepté : demandez à l'administrateur de le réinitialiser.

**Mot de passe oublié.** Sur la page « Connexion », cliquez sur « Mot de passe oublié ? », indiquez votre
identifiant ou votre courriel professionnel, puis cliquez sur « Recevoir un code ». Si un compte correspond, un
code à 6 chiffres vous est envoyé par courriel (valable 10 minutes) ; le message affiché est le même que le
compte existe ou non. Cliquez sur « Saisir le code reçu », saisissez le code et un nouveau mot de passe, puis
« Enregistrer le mot de passe ». Si aucun courriel n'arrive, adressez-vous à l'administrateur : il peut
réinitialiser votre mot de passe. Après 15 codes erronés en 24 heures, plus aucun code n'est accepté pour votre
compte jusqu'à la fin de ces 24 heures (le message reste « Code invalide ou expiré. ») : demandez alors une
réinitialisation à l'administrateur.

**Connexion refusée.** Le message « Identifiant ou mot de passe incorrect. » est le même quelle que soit la cause
(mot de passe erroné, compte inconnu, désactivé ou verrouillé). Après cinq échecs consécutifs, la connexion est
bloquée pendant 15 minutes ; l'administrateur peut la rétablir plus tôt en réinitialisant votre mot de passe. Le
message « Trop de tentatives, réessayez dans quelques minutes. » signifie que trop d'essais sont venus de votre
réseau (par exemple de tout votre site) : patientez le temps indiqué, au plus 15 minutes, puis réessayez.

**Durée de la session.** Votre session se ferme après 8 heures, ou après 30 minutes sans activité : « Votre
session a expiré. Veuillez vous reconnecter. »

### 1.3 Profil, aide, déconnexion

Le menu utilisateur (en haut à droite) affiche votre nom, votre adresse et votre rôle. Il propose
« Mon compte », « Changer mon mot de passe », « Visite guidée de la plateforme » et « Se déconnecter ».
Dans « Mon compte », vous pouvez changer votre mot de passe (vos autres sessions ouvertes sont alors fermées) et
activer ou désactiver, **vous seul**, le réglage facultatif « Demander un code par courriel à chaque connexion »
(désactivé par défaut). Activé, ce réglage ajoute après le mot de passe l'étape « Vérification en deux étapes » :
saisissez le code à 6 chiffres reçu par courriel (valable 10 minutes), puis « Valider le code ». Il ne peut être
activé que si l'envoi de courriels est configuré et si une adresse de courriel est enregistrée sur votre compte ;
pour le désactiver, confirmez avec votre mot de passe actuel. Si le code ne vous parvient plus, l'administrateur
peut le désactiver pour vous (mais jamais l'activer à votre place).

Votre direction, indispensable pour répondre aux constats, est renseignée par
l'administrateur : si elle est absente, contactez-le (voir section 8). Aucune entrée « Aide » n'existe à ce jour.

### 1.4 Notifications et recherche

La cloche affiche « Notifications, N non lues » ; cliquez une notification pour ouvrir l'objet concerné ;
« Tout marquer comme lu ». La page « Voir toutes les notifications » offre les onglets « Non lues » et « Toutes ».
La recherche de l'en-tête (deux caractères au moins) ne retourne que vos éléments : constats soumis ou validés de
votre entité, vos actions, les documents autorisés.

## 2. Ce que vous voyez et ce que vous ne voyez pas

- **Missions** : seulement celles dont l'**ordre de mission est émis** et où vous êtes affecté comme « Audité ». Sinon :
  « Vous n'êtes affecté à aucune mission. » ou « Aucune mission ne concerne votre entité pour le moment. »
- **Constats** : uniquement ceux de votre entité, une fois **soumis ou validés**. Les brouillons ne sont pas visibles.
- **Non visibles** : fiches de test et pièces de l'équipe d'audit, notes internes d'entretien, rapport avant diffusion.
- **Réunions** : consultables en lecture.
- **Documents** : seulement ceux que la plateforme autorise pour vos missions (« Aucun document ne concerne vos missions pour le moment »).

Une mission d'une autre entité n'apparaît nulle part : les messages sont « Mission introuvable. », « Ce constat est introuvable. »,
« Action introuvable. ».

## 3. Avis sur le référentiel d'audit (étape VI)

1. Ouvrez la mission, onglet « Référentiel d'audit ». S'il n'est pas diffusé : « Le référentiel d'audit n'est pas encore diffusé ».
2. Sinon, « Donner mon avis » : choisissez le type d'avis ; le commentaire est obligatoire pour des remarques.
3. Votre avis est enregistré ; il ne bloque pas la suite de la mission.

## 4. Répondre au rapport provisoire (étape XV)

À la transmission du rapport provisoire, vous recevez une notification. Un délai de réponse est fixé (1 à 60 jours).

### 4.1 Répondre à un constat

1. Ouvrez la mission, onglet « Rapport provisoire » : lisez « Il vous reste N jours pour répondre ».
2. Dans « Constats de mon entité », cliquez « Répondre » sur le constat.
3. Choisissez votre position : **Accord** ou **Désaccord**. En cas de désaccord, motivez-le (« Le commentaire est obligatoire. » /
   « Motivez votre désaccord. »). « Continuer ».
4. Lisez le texte de confirmation, cochez « Je confirme », puis « Envoyer ma réponse ».
5. Le message « Réponse enregistrée le … à … Empreinte : … » confirme.

Vous pouvez répondre plusieurs fois : les réponses forment un historique par cycle. Une réponse après la date limite
est marquée « Hors délai ». Une fois le délai clos : « La période de réponse au rapport provisoire est close. »

## 5. Proposer des actions : le plan d'actions (étape XVI)

### 5.1 Ajouter une action

1. Onglet « Plan d'actions ». Sous une recommandation de votre entité : « Ajouter une action ».
2. Renseignez la mesure corrective (obligatoire), le responsable, l'échéance (une date passée est refusée : « L'échéance ne peut pas être antérieure à aujourd'hui. »), l'indicateur et les moyens.
3. « Modifier » ou « Supprimer » tant que le plan est ouvert. Le plan n'est modifiable que pendant les étapes XV et XVI ; ensuite il est en lecture seule.
4. Lisez « Contrôles du plan d'actions » : « Actions incomplètes… », « Engagements manquants ou à renouveler… ».

[Capture à insérer : CAP-AU-08 — Plan d'actions, ajout d'une action]

### 5.2 Confirmer votre engagement

Si vous êtes responsable d'actions : « Confirmer mon engagement » (case à cocher puis confirmation). Si vous modifiez ensuite une action,
l'engagement passe à « À renouveler ».

### 5.3 Accepter le risque

Pour une recommandation qui n'a **aucune action**, vous pouvez décider d'accepter le risque :

1. « Accepter le risque » ; saisissez la justification (obligatoire).
2. Cochez « Je confirme accepter ce risque au nom de ma direction. » puis « Confirmer l'acceptation ».
3. Le message « Risque accepté le … par … » apparaît. Pour ajouter ensuite une action, il faut d'abord « Retirer l'acceptation » (vous ou le RAI).

Une recommandation sans action ni acceptation est listée dans « Recommandations sans suite ».

## 6. Exécuter vos actions après la diffusion

Vos actions se trouvent dans le tableau de bord (« Actions ouvertes », « En retard »), dans « Recommandations » (onglet « Actions », filtre
« Mes actions ») et dans la cloche.

### 6.1 Cycle d'une action

Statuts : « À lancer », « En cours », « Réalisée, à vérifier », « Vérifiée », « Clôturée ».

1. Ouvrez l'action, « Démarrer ».
2. Déposez une **preuve de mise en œuvre** (libellé et fichier) et ajoutez des **points d'avancement**.
3. « Déclarer réalisée » (commentaire obligatoire). Sans preuve : « Déposez au moins une preuve de mise en œuvre. »
4. La vérification revient à un auditeur ; la clôture au RAI. Vous ne pouvez ni vérifier ni clôturer. Si l'auditeur rejette, l'action vous revient avec
   le « Motif du dernier rejet ».

[Capture à insérer : CAP-AU-10 — Page d'une action : démarrer, preuve, déclarer réalisée]

### 6.2 Demander un report d'échéance

1. « Demander un report » : nouvelle échéance postérieure à l'échéance courante (« La nouvelle échéance doit être postérieure à l'échéance courante ») et motif obligatoire.
2. Le RAI accepte ou refuse (avec commentaire). Votre échéance courante change si le report est accepté ; l'échéance initiale et le nombre de reports restent visibles.
3. Suivez vos demandes dans « Mes demandes de report ».

### 6.3 Proposer l'abandon

« Proposer l'abandon » avec une justification. Le RAI accepte (« Abandonnée (justifiée) ») ou rejette.

### 6.4 Relances

Avant l'échéance, le jour même et en cas de retard, vous recevez des relances par notification et par courrier électronique si votre adresse est renseignée.

3. Si vous en êtes destinataire interne : « Accuser réception » (confirmer). « Accusé de réception enregistré le … ».

## 8. Règles à connaître

- **Votre direction doit correspondre à l'entité du constat.** Sinon : « Ce constat concerne une autre entité que votre direction. » ; si elle est vide : « Votre direction n'est pas renseignée sur votre profil : vous ne pouvez pas répondre. » Contactez l'administrateur.
- **Confirmation explicite** : aucune case de confirmation n'est pré-cochée ; chaque confirmation est horodatée avec une empreinte.
- **Quatre yeux** : vous ne vérifiez ni ne clôturez vos propres actions.
- **Jalons** : les jalons VI, X, XIII et XVIII sont validés par le RAI ; votre avis sur le référentiel n'est pas un jalon.
- **Gels** : une mission suspendue, annulée ou clôturée est en lecture seule.
- **Journal** : chaque action a une « Chronologie » (qui, quand, quoi). Les preuves déposées ne se modifient pas.
- **Fichiers acceptés** : jusqu'à 50 Mo ; les fichiers vides, exécutables ou avec macros sont refusés.

## 9. Messages fréquents

| Message | Signification |
|---|---|
| « Seul l'audité responsable de l'entité du constat peut répondre. » | Votre direction n'est pas celle de l'entité. |
| « La période de réponse au rapport provisoire est close. » | Le délai est dépassé. |
| « Motivez votre désaccord. » | Un commentaire est requis. |
| « Déposez au moins une preuve de mise en œuvre. » | Preuve manquante avant de déclarer l'action réalisée. |
| « Le motif est obligatoire. » | Report ou abandon sans motif. |
| « Mission introuvable. » | Mission inexistante, non diffusée à vous, ou ordre non émis. |
| « Vous n'avez aucune notification. » | Liste vide. |
| « Le tableau de bord n'a pas pu être chargé. » | Cliquez « Réessayer ». |

## 10. Questions fréquentes

**Je ne vois pas la mission qui concerne ma direction.** L'ordre de mission n'est pas encore émis ou vous n'êtes pas affecté comme « Audité » : contactez le RAI.

**Puis-je modifier ma réponse ?** Vous pouvez répondre de nouveau ; l'historique conserve les réponses précédentes.

**Puis-je supprimer une preuve déposée ?** Non, elle est conservée ; vous pouvez la « Renommer ».

**Qui contrôle que mon action est réalisée ?** Un auditeur la vérifie, puis le RAI la clôture.

## 11. À confirmer

- V-12 : une même personne peut-elle tenir plusieurs rôles dans une mission ?
- Écart connu : le compte rendu d'une réunion non encore tenue peut être lisible par l'audité.
- Libellé exact de l'avis (types d'avis) et du bouton de dépôt de preuve à relever à l'écran.
- Ordre exact des onglets de mission pour un audité.
- Entrée « Aide » du menu : non présente.
