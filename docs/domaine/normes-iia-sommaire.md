Implications produit :
- documentation de mission conservée, horodatée et non altérable (14.6 Documentation de la mission) → piste d'audit, versions figées à la validation ;
- supervision des missions (12.x / 14.x) → circuit de validation RAI à chaque jalon ;
- suivi des recommandations (15.2) → module « plan d'actions » avec échéances, responsables, statuts, relances ;
- confidentialité (5.2) → rôles et périmètres d'accès stricts, journal des consultations.
